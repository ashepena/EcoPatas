# EcoPatas — Site institucional

Site fictício criado com Webnode como trabalho escolar, para uma organização
de adoção de animais e preservação da natureza.

**Site online:** https://ecopatas-ecc8ca.webnode.pt/

## O que foi feito

- Planeamento da estrutura e conteúdos do site
- Design e layout com o construtor Webnode
- Redação de textos institucionais
- Publicação e gestão do domínio
